* `ops/workflows/qa.js` held a dynamic `import()` that the Workflow runtime refuses; the selfcheck compiles scripts without running them, so nothing caught it before the first day under the new contract. It cost a hand-run QA (about 30 minutes, no expert review, a Haiku proofread whose findings could not be triaged by a second agent) and, with the QA tokens spent by hand, left too few workflow tokens for a revise loop. The architect kaizen removed the import and added a guard test for all workflow scripts the same day.

The rule that every listed or attributed source must be a verified research entry makes search-only claims look like defects. They shipped as known issues.
* The stranger cold read counts first-screen labels and site chrome ("Sonnet Every Day", "Day 4") as unexplained terms, so a correct answer still tripped the three-terms rule.
* A single-quoted `pgrep -f` wait loop matched itself and ran to its time limit; the verify result had already been written. Wait on a result file, not on pgrep -f.
